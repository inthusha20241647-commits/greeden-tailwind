# 🌿 GreenDen – Plant Website

A responsive plant website built using **HTML , Tailwind CSS & JavaScript**. GreenDen includes a home page, product page with search functionality, and a contact page.

## 🌱 Features

* 🏠 **Home Page**

  * Hero section
  * About Us section
  * Best Sellers
  * Customer Reviews
  * Newsletter section

* 🪴 **Product Page**

  * Responsive product grid
  * Product images and prices
  * 🔍 Product search functionality
  * Products are filtered dynamically as the user types

* 📩 **Contact Page**

  * Name input
  * Email input
  * Phone number input
  * Company input
  * Message textarea
  * Send Message button

* 📱 **Responsive Design**

  * Mobile-friendly layout
  * Desktop navigation
  * Responsive product grid

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 Tailwind CSS
* ⚡ JavaScript
* 🖼️ SVG Icons

## 🔍 Product Search

The product page includes a JavaScript search function.

When the user types a product name, JavaScript checks the product names and:

* ✅ Shows matching products
* ❌ Hides products that don't match

For example, searching for **"Rose"** displays the Rose Plant products.

## 💻 How to Run Locally

1. Clone the repository.

2. Open the project folder in **VS Code**.

3. Open `index.html`.

4. Use **Live Server** or open the HTML file in your browser.

5. Navigate between:

   * 🏠 Home
   * 🪴 Products
   * 📩 Contact
